# CV Instal PWA v68

Dit is de installatielaag voor de bestaande CV Instal Google Apps Script-app.
De werkende v67 backend en Google Sheet worden niet gewijzigd.

Upload alle bestanden uit deze map naar de root van de GitHub repository `cv-instal-app`.
Daarna GitHub Pages inschakelen via Settings > Pages > Deploy from a branch > main / (root).
